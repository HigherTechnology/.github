# Higher Technology

This is a personal organization that also serves a small group. It's where I publish software meant to be used as a dependency in other projects: keeping it public makes it easier to move around and pull in wherever it's needed.

Each project here exists to solve a problem I've run into. I think some of them may be useful to others, but nothing here is advertised or actively promoted.

## About the name

The name reflects the aim: in select areas, the software here is intended to be more evolved than what's available elsewhere. Much of it comes from personal experience: running into the limits of existing tools, then iterating on a better approach over time.

## Please note

- **Contributions are not accepted.** Issues and pull requests may be closed without review.
- **No security guarantees.** Treat anything published here with scrutiny and caution, and review it yourself before depending on it.
- **Breaking changes are very likely.** APIs and behaviour can change at any time without notice. Pin exact versions if you depend on anything here.
- **Anything may be abandoned.** Projects can stop being maintained, or be removed, at any time.
- **Take the idea, not necessarily the code.** If something here is useful to you, you're encouraged to learn from it and build your own version.

## How things are made

- **Ideas are human.** Every idea and design here comes from a person.
- **Text is AI-assisted.** Written material such as READMEs and documentation is either AI-generated or touched up with AI.
- **Serious code is generally human-written.** Code meant to last is written by hand for the most part.
- **Experimental code may be generated.** When something experimental is needed right away, it may be generated and published here as is.
- **Agentic coding is used to move faster, not to skip understanding.** When something has to get done, AI coding agents may be used to speed it along, without giving up much in understanding what the code does.
